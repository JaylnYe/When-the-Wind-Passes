# 风经过

全屏树木交互原型。页面没有可见文字、计数或减少动态开关；右下角保留轻吹与重置两个图标按钮，支持键盘和读屏。

运行：`python3 -m http.server 8765 --directory dist`，打开 http://localhost:8765 。无需构建。Node 18+ 模拟测试：`node --test tests/*.test.js`。

## 互动与长叶

一棵可控枝干构成的树，900 片独立叶子。按住鼠标或单指划动产生局部风；原叶直接脱落，留下真实缺口。树冠少于 675 片时启动补叶，逐片恢复到完整状态。每 0.16 秒最多开始长一片，新叶用 2.4 秒由小变大，并有 3 秒成熟保护期。全树至少保留 360 片成熟叶，各细枝至少保留 3 片，避免吹秃。落叶消失后才复用其对象，数量不会无限增长。

没有页面级减少动态开关，但仍自动尊重系统偏好：关闭摇摆、空间飘落和缩放生长，使用原位淡入淡出。固定 120 Hz 物理步，无操作且无生长任务时休眠，后台暂停，不补算离开期间的时间。

## 验证

七项模拟测试覆盖静止、身份守恒、脱落连续性、局部风、系统减少动态、重置、帧率独立，以及持续吹动不吹秃、最终恢复长满。浏览器检查脚本在 qa/；先安装 Playwright，启动本地服务后运行。可用 CHROME_EXECUTABLE_PATH 指定本机 Chrome。已检查桌面与 390×844 模拟布局；不代表 iOS/Android 真机性能验收。

## 素材与边界

5 个运行时叶片纹理来自用户提供的 wind_tree_realistic_mobile_assets.zip（leaf-01、04、07、11、18）。枝条、背景、布局与代码为重建；没有固定树冠底图。其他纹理作为参考保留。原素材来自扁平参考图近似分离，未额外确认商业授权。

当前为完整树的结构与交互原型，非写实原画还原。叶柄转轴与地面接触采用简化处理；任意输入采样率下的严格轨迹重采样、原画细节和真机表现仍需后续验证。

## 树形重建

人工配置主干与不对称分叉；固定种子生成长度、角度不同的细枝和叶簇芽点。叶片分前后两层，绿黄纹理在加载时预处理；枝干使用渐细轮廓与细纹，补充根部和接地阴影。静止形态固定，风只影响枝条姿态。当前 900 片叶的手机真机性能仍待测量。
