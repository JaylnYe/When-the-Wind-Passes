# 风经过

一款以亲近自然为主题的全屏互动小工具。指尖划过树冠，枝条先回应，花叶随后飘落并在落地后慢慢消失，树冠会逐片恢复。可以切换梧桐、银杏、樱花、垂柳和蓝花楹；右下角提供轻吹与重置，左下角可开关声音。

运行网页版：`python3 -m http.server 8765 --directory dist`，然后打开 `http://localhost:8765`。页面无需构建；声音通过 Web Audio 生成，浏览器可能要求首次触摸后才能播放。

运行测试：`node --test tests/*.test.js`。测试覆盖风场、枝叶运动、飘落与再生、减少动态偏好和音频控制。自动化浏览器检查不能代替 iOS、Android 真机的触控、声音和性能验收。

`branding/` 中保存图标方案；当前简约版为 `风经过-简约图标-512.png`。美术素材中，一部分叶片来自用户提供的参考素材，其余植物纹理由 imagegen 生成；用于公开发布时，请另行确认第三方参考素材的使用权。
