# 风经过 · 一枝练习

用于验证独立枝叶、局部风、真实脱落和回弹的可运行样片。它不是原画的整树还原。

运行：在本目录执行 `python3 -m http.server 8765 --directory dist`，打开 http://localhost:8765 。纯静态 HTML/CSS/JavaScript，无构建或运行时依赖。模拟测试：Node 18+ 下执行 `node --test tests/*.test.js`。

按住鼠标或单指拖动：慢划轻摆，快划产生更强局部风。轻吹一下按钮提供同类风脉冲；重新长满恢复 54 片叶子。减少动态跟随系统偏好，也可手动覆盖，每次手势最多淡出 3 片叶子。

主枝和五根细枝采用可控贝塞尔曲线与角弹簧，全部叶片为独立对象。使用固定 120 Hz 物理步，无操作时休眠，后台暂停；不补算后台经过的时间。所有叶片均能移除，无固定冠叶底图。

## 素材来源

5 个叶片纹理（leaf-01、04、07、11、18）来自用户提供的 wind_tree_realistic_mobile_assets.zip。原包说明其来自扁平写实参考图的近似分离；使用不代表已确认商业授权。枝条、叶柄、背景、布局和交互代码为本样片重建。未使用整树静态图片作为动画底图。其他暂存叶片纹理不参与运行。

## 验证与边界

已覆盖静止不落叶、叶片身份守恒、脱落位置与角度连续、局部风支持范围、风历史上限、回稳与回收、减少动态配额、重置，以及 30/60/120 Hz 固定步结果一致性。

浏览器检查使用本机 Chrome 无头模式：轻吹按钮、重置、减少动态开关、390×844 布局无横向溢出；另有鼠标慢划/快划对比。浏览器检查脚本在 `qa/`：先执行 `npm install --no-save playwright` 和 `npx playwright install chromium`，启动本地服务后执行 `node qa/browser-check.mjs` 与 `node qa/pointer-check.mjs`。也可用 `CHROME_EXECUTABLE_PATH` 指定已有 Chrome 路径。截图为桌面和模拟移动尺寸，不等于 iOS/Android 真机验证。

视觉是疏朗枝条的功能样片；纹理分辨率和叶柄 pivot 采用近似值，地面接触也采用简化包围范围。尚未完成整树重建、原画视觉验收、触屏真机及性能验收。输入轨迹当前按事件时间归一化发射，尚未完成任意事件采样率下的严格轨迹重采样验证。
